clipscript example · plain HTML

Closed deal to team channel

A Sales Accelerator deal closes, an n2N workflow runs, and the team hears about it in Plank. The whole film below is one JSON file: closed-won.clip.json.

Use it in your page

<script src="https://unpkg.com/clipscript/dist/clipscript.min.js" defer></script>
<clip-script src="closed-won.clip.json"></clip-script>

Or with npm: npm install clipscript, then import 'clipscript' once and use the same tag in React, Vue, Svelte, or plain HTML.
