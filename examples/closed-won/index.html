Cueflick example · plain HTML

Closed deal to team channel

A Sales Accelerator deal closes, an n2N workflow runs, and the team hears about it in Plank. The whole film below is one JSON file: closed-won.clip.json.

Use it in your page

<script src="https://unpkg.com/cueflick/dist/cueflick.min.js" defer></script>
<cue-flick src="closed-won.clip.json"></cue-flick>

Or with npm: npm install cueflick, then import 'cueflick' once and use the same tag in React, Vue, Svelte, or plain HTML.
